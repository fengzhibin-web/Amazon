# ExcelExtractor（Excel / Gemini 桌面处理工具）

## 功能概览

1. **Excel去重提取**：按 `id` 去重并导出 Excel。  
2. **生成Gemini批量输入**：生成 `gemini_batch_XXX.txt`，每个文件顶部带 `IDS: ...`。  
3. **Gemini TSV转纵向表**：支持文件导入或直接粘贴 TSV 文本，输出纵向 `字段 | 内容` Excel。  
4. **任务列表**：显示每次处理的状态、数量、输出和备注。  

## 安装依赖

```bash
pip install -r requirements.txt
```

## 打包 EXE

在 `project` 目录双击 `build.bat`，输出：

```text
dist\ExcelExtractor.exe
```

## Gemini 批量输入 TXT 规则

- 每批 N 条（默认 10）
- 文件名：`gemini_batch_001.txt`、`gemini_batch_002.txt`...
- 顶部一行 IDS：

```text
IDS: 683443087,683443086,683443085
```

- IDS 行后空一行，再写原 `[PRODUCT]` 区块

## Gemini TSV 转纵向 Excel

### 输入方式

- **文件导入**：`.txt` / `.tsv` / `.xlsx` / `.xls`
- **粘贴文本**：支持直接粘贴 Gemini 网页 TSV 代码块

### 解析鲁棒性

- 自动移除 ```tsv ... ``` 代码块包裹
- 如果代码块前有说明文字，优先提取代码块内容
- 自动去除前后空行
- 支持把字面量 `\n` 还原为真实换行（网页复制常见）
- 按 Tab 解析，第一行为表头
- 自动跳过重复出现的表头行，避免字段错位
- 列名自动清洗（去空格/不可见字符）
- 单元格会清理外围双引号与尾部空白

### 纵向字段顺序（严格按 Gemini 字段名）

`id`、`原始标题`、`原始描述`、`违禁词检验`、`品牌识别`、`AI_通用标题_EN`、`AI_通用标题_CN`、`AI_关键词_EN`、`AI_关键词_CN`、`AI_卖点_EN_1..5`、`AI_卖点_CN_1..5`、`AI_规格描述_EN`、`AI_规格描述_CN`。

> 不新增 `AI状态/产品ID` 等字段，不改名，不合并字段，仅重排顺序。

### 卖点/规格描述清洗

对 `AI_卖点_*` 和 `AI_规格描述_EN/AI_规格描述_CN` 输出时清理开头序号（如 `1.`、`2、`、`(3)`、`4：` 等），仅清理开头，不影响正文数字。

规格描述新格式支持使用 ` || ` 分隔多条内容，导出时会在**同一个单元格**内按换行+编号展示；若输入是旧格式 `AI_规格描述_EN_1..5 / AI_规格描述_CN_1..5`，会自动兼容合并。

### 输出

- 输出目录可选
- 默认文件名：`gemini_result_vertical_YYYYMMDD_HHMMSS.xlsx`
- 可手动改名；无 `.xlsx` 后缀会自动补全

## 任务列表

字段：任务名、输入来源、状态、产品数量、输出文件、创建时间、完成时间、备注。  
状态：待处理 / 处理中 / 已完成 / 失败（当前流程使用 处理中/已完成/失败）。

## 拖拽上传

已接入 `tkinterdnd2`：

- Excel去重提取页支持拖拽 `.xlsx/.xls`
- Gemini批量输入页支持拖拽 `.xlsx/.xls`
- Gemini TSV转纵向表页支持拖拽 `.txt/.tsv/.xlsx/.xls`

若环境缺少拖拽组件，拖拽区会显示提示，并可继续用“选择”按钮操作。
